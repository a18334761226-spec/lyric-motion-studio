## 简介

开源了一个「文字 → 竖屏短视频」的工具：
画面由 DeepSeek 直接写完整 SVG（信息图/文字卡/插画），Chrome 截图成 1080×1920，Edge-TTS 配音，ffmpeg 本地渲染。
纯 CPU、无生图费用，一支 3 分钟片约 0.8 元、5~10 分钟出片。
支持：目标时长扩写/精简、自动开场白、1.3 倍语速、底部安全区字幕、自动封面、抖音发布包、每日选题自动出片。
一条命令看效果（不需要 Key）：npm run demo
仓库（MIT）：https://github.com/a18334761226-spec/lyric-motion-studio

## 口播脚本结构（用于录视频/演示）

1. 钩子：一支 3 分钟视频，生图 API 要花多少钱？我用 0.8 元做完了，而且没有显卡。
2. 展示：贴一段口播稿 → 自动切段 → 每段一张信息图 → 配音 → 字幕 → 成片（屏幕录制）。
3. 原理：DeepSeek 写 SVG，Chrome 截图；不是生图模型，所以零显存、零按张计费。附成本表。
4. 细节：1.3 倍语速、开场白、目标时长扩写/精简、抖音安全区、自动封面与发布包。
5. 门槛：`npm run demo` 不需要 Key；`docker run` 一条命令起服务。
6. 行动：仓库链接 + 问「你会拿它做什么内容」。

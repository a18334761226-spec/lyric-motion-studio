## 正文

最近把自己做短视频时反复踩的坑整理成了一个开源项目：**Lyric Motion Studio**（名字有点旧，现在做的是通用成片）。

核心思路和常见 AI 视频工具不同：**画面不是调文生图 API，而是让 DeepSeek 文本模型直接写完整 SVG**，再用 Chrome 无头模式截图成 1080×1920。好处是：

- 不需要显卡（纯 CPU，4–8GB 内存就行）
- 没有按张计费的生图成本
- 每一镜都能精确控制文字、箭头、信息图结构，画面和台词逐句对应

配音走 Edge-TTS（免费），渲染走 ffmpeg（本地），所以整条链路除了 DeepSeek 的文本 token 外没有别的费用。

实测数据（一支 3 分钟片）：
- 29 次 LLM 调用，约 11.9 万 token
- 模型费用 ≈ ¥0.80
- 普通 CPU 约 5.8 分钟出片
- 成片 21.7 MB

功能上还有：目标时长自动扩写/精简文稿、自动开场白、1.3 倍语速、底部安全区字幕（适配抖音播放页）、自动生成海报封面、抖音发布包（成片/封面/标题/简介/话题）、每日选题自动出片。

**一条命令就能看效果，不需要任何 API Key：**

```bash
npm install
npm run demo
```

会渲染一支约 35 秒的演示片。完整需要 `npm run build && npm start`，或直接 `docker run`。

仓库（MIT）：https://github.com/a18334761226-spec/lyric-motion-studio
